# 바로배터리 전체 원본 소스

2026-09-04 체크형 문자 문의 화면 반영본입니다.

## 포함 파일
전체 페이지, 컴포넌트, 스타일, 콘텐츠 데이터, 이미지, 폰트, 아이콘, 프로젝트 설정, 의존성 잠금 파일, Sites 호스팅 식별 설정, 구조·CMS 설계 문서를 포함합니다.
외부 패키지 설치 폴더(node_modules), 자동 생성 빌드 결과(dist), 개발 캐시, Git 이력은 제외했습니다. 필요한 패키지는 package-lock.json으로 다시 설치할 수 있습니다.

## 실행
Node.js 22.13.0 이상을 설치하고 압축을 푼 baro-battery-source 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소로 접속하세요.

## 확인 및 빌드
```sh
npm run lint
npm run build
```

## 주요 수정 위치
- app/: 페이지와 전체 스타일
- components/site/: 헤더·푸터·체크형 문자 문의·차종/지역 탐색
- lib/content.ts: 차종·지역·포스팅·FAQ 데이터
- lib/site-config.ts: 브랜드·사이트 주소·전화번호·카카오 주소
- public/: 이미지·폰트·아이콘
- docs/structure-and-cms.md: 구조와 CMS 확장 안내

## 현재 동작
차종·연식은 필수, 배터리·경고등 사진은 선택입니다. 증상을 체크하면 문자 미리보기가 바뀝니다.
문자 수신번호와 카카오 주소는 아직 미설정입니다. phone에 운영 번호를 설정하면 문자 앱에 내용을 전달하며, 사진 첨부와 최종 전송은 사용자가 문자 앱에서 직접 진행합니다.
사이트는 UI 시안 상태로 예시 콘텐츠·후기를 포함합니다. CMS 서버와 문의 저장 기능은 구현되어 있지 않습니다.

## 호스팅과 화면 이동
.openai/hosting.json에는 기존 Sites 프로젝트 연결 정보가 포함됩니다. 다른 프로젝트로 배포할 경우 새 프로젝트의 설정을 사용하세요.
components/site/site-link.tsx의 일반 문서 링크는 배포 환경의 화면 전환 문제를 해결한 방식입니다.

SOURCE-MANIFEST.json에는 원본 파일별 SHA-256과 소스 기준 커밋을 기록했습니다.
